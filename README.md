# 일본 마운자로 방문 도우미 — 웹앱 프로토타입

일본에서 마운자로(マンジャロ)를 자가치료 목적으로 처방·수령하고 한국에 반입할 때 필요한 **공개 정보 정리 + 방문 준비 도구**를 모은 모바일 우선 웹앱입니다. 빌드 도구·외부 CDN·서버가 필요 없는 **단일 HTML 파일**입니다.

- 앱: [`index.html`](./index.html)
- 테스트: [`test_app.py`](./test_app.py) (문법·로직), [`test_structure.py`](./test_structure.py) (DOM·문구 가드레일), [`test_smoke.py`](./test_smoke.py) (초기화·탭·필터·계산 경로 실행)

> **이 앱이 하지 않는 일**: 의료기관 알선, 예약 대행, 의약품 광고·판매, 가격 순위 매기기, 수수료 수취.
> 예약·결제·진료는 전부 해당 기관과 이용자 사이에서 이루어집니다.

### 안전장치

- 상단 고정 배너 + 모달 + 푸터에 “알선·예약 대행·의약품 광고 아님, 처방·용량은 현지 의사 판단” 명시.
- `최저가`, `1위`, `강력 추천`, `보장` 같은 유인·과장 표현 미사용(테스트로 검사).
- 가격은 전부 **각 기관 공식 페이지 공개가**이며 `2026-11 확인`으로 표기. 공개되지 않은 항목은 “공식 페이지 확인 안 됨”으로 표기.
- 이름·금액 등 입력값은 서버로 전송되지 않음. **체크리스트 상태와 계산기 설정(환율·금액)** 만 브라우저 localStorage에 저장되며, 이름은 저장하지 않음.
- 특정 개인의 이름·연락처·여권 표기·여행 일정 등 개인정보 미포함(테스트로 검사).

## 4. 대마도(쓰시마) 수령 가이드

**섬 안에서 마운자로를 처방하는 방문형 병원은 2026-11 공개 안내 기준 0곳**입니다. 실제 경로는 다음과 같습니다.

1. **출발 약 1주일 전** 한국에서 클리닉 온라인 진료 (폰타나클리닉은 한국에서 예약·상담 가능 안내, 카카오톡 `fontanaclinic`)
2. 진료 시 **대마도 숙소 또는 야마토 운수 영업소**를 수령지로 지정 — 냉장(쿨) 택배 보통 **2~3일**
3. 부산항 배편 입도 후 수령 — **히타카츠 약 1시간 20분 / 이즈하라 약 2시간 20분**(선사·편별 상이)

### 주의

- 보관은 **도착일 포함 최대 3일, 연장 불가**. 지나면 발송 클리닉으로 반송됩니다(재발송 비용·환불 불가 사례 있음). 수령 희망일은 **여행 전날**로.
- 수령 시 **여권 + 송장번호** 필요. 송장번호는 클리닉 또는 야마토 안내 메일에서 확인.
- 기상 결항 대비 **하루 여유**. 배가 결항해도 약은 이미 영업소로 가 있습니다.
- 숙소의 **냉장 보관·대리 수령 가능 여부**를 예약 전에 직접 확인(민박·에어비앤비는 영업소 권장).
- 쿨택배는 **0~10°C**, 마운자로 권장 보관은 **2~8°C**. 도착 즉시 냉장, **동결 금지**.
- 한국 체류 중 비대면 진료로 받는 경우 약은 **일본 국내로만** 배송됩니다. 한국 반입은 **휴대 반입 원칙**(3개월분·12펜)과 통관 요건을 사전 확인.
- 영업소 정보·운항 시간은 바뀔 수 있습니다. 발송 전 **야마토 운수 영업소 검색**과 선사 운항표로 재확인하세요.

## 6. 무료 배포 (5분)

정적 파일 1개라 어디든 올라갑니다. **인덱스 파일명은 `index.html`** 이어야 루트 접속 시 바로 열립니다.

### A. Vercel

```bash
cd projects/japan-mounjaro-helper
npx vercel            # 로그인 후 안내에 따라 진행 (프레임워크: Other, 빌드 없음)
npx vercel --prod     # 프로덕션 배포
```
또는 [vercel.com/new](https://vercel.com/new)에서 폴더를 드래그&드롭.

### B. Cloudflare Pages (무료, 대역폭 무제한)

```bash
cd projects/japan-mounjaro-helper
npx wrangler pages deploy . --project-name japan-mounjaro-helper
```
또는 대시보드 → **Workers & Pages → Create → Pages → Upload assets** → 폴더 업로드.

### C. GitHub Pages

```bash
cd projects/japan-mounjaro-helper
git init && git add index.html README.md && git commit -m "add prototype"
git branch -M main
git remote add origin https://github.com/<계정>/japan-mounjaro-helper.git
git push -u origin main
```
저장소 → **Settings → Pages → Source: Deploy from a branch → main / (root)** → `https://<계정>.github.io/japan-mounjaro-helper/`

### 배포 후 체크

- 모바일에서 실제 기기로 열어 폰트·줄바꿈·하단 탭 가림 확인

## 7. 공개·수익화 전 법률·컴플라이언스 체크리스트

> 아래는 **일반 정보 정리이며 법률 자문이 아닙니다.** 공개·광고·수익화 전에는 반드시 한국·일본 변호사(의료/약사/표시광고) 검토를 받으세요. 특히 **수익 모델을 붙이는 순간** 규제 성격이 달라집니다.

### 한국

- [ ] **의료법 제27조(무면허 의료행위)·제27조의2/환자 알선·유인 금지**: 예약을 대신 잡아주고 수수료를 받거나, 특정 기관을 상위에 노출해 대가를 받는 구조는 **영리 목적 환자 알선**로 문제될 수 있음. → 링크 연결·정보 제공에 그치고, 대가성 있는 노출·순위·중개를 두지 않는다.
- [ ] **의료법 제56조(의료광고)**: 치료 효과 보장, “최고·최신·유일”, 다른 기관과의 비교, 체험담에 기반한 유인 표현 금지. → “공개된 일반 정보” 서술만 유지.
- [ ] **약사법 제68조(의약품 광고)**: 허가된 효능·효과 범위를 벗어난 광고(예: 다이어트 목적 효능 보장) 금지. **의약품 온라인 판매·중개 금지**. → 판매·결제·배송 중개 기능을 넣지 않는다.
- [ ] **약사법상 자가치료 목적 반입 의약품의 양도·판매 금지**: 앱에서 재판매·양도·공동구매를 유도하는 기능·문구를 두지 않는다.
- [ ] **표시·광고의 공정화에 관한 법률**: 거짓·과장, 부당한 비교, 중요 정보 누락 금지. 가격·조건의 기준일과 출처를 표시.
- [ ] **개인정보보호법**: 회원가입·상담 폼·분석 도구를 추가하면 수집 항목 최소화, 처리방침 공개, 국외 이전 고지, 만 14세 미만 처리, 쿠키 동의 검토. (현 프로토타입은 서버 수집 없음)

- [ ] **관세·세무**: 약값의 부가세(VAT)와 별개로 **일본 소비세 면세(Tax-Free) 대상 아님**, 한국 입국 시 800달러 합산·자가치료용 12펜 기준 안내 문구 유지.
