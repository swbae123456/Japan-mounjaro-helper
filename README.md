# 일본 마운자로 방문 도우미 — 웹앱 프로토타입 (KO/EN)

일본에서 마운자로(マンジャロ)를 자가치료 목적으로 처방·수령해 자기 나라로 가져갈 때 필요한 **공개 정보 정리 + 방문 준비 도구**를 모은 모바일 우선 웹앱입니다. **한국어(KO)와 영어(EN)를 상단에서 1탭으로 전환**할 수 있고, 오른쪽 위 `한국어 | EN` 버튼으로 언제든 바꿀 수 있습니다. 빌드 도구·외부 CDN·서버가 필요 없는 정적 앱입니다.

- 앱: [`index.html`](./index.html) (기관 데이터 폴백 내장)
- 기관 데이터: [`clinics.json`](./clinics.json) — 11곳, 한국어·영어 필드. 앱은 실행 시 `fetch('./clinics.json')`을 시도하고, `file://`·오프라인·실패 시 `index.html` 내장 사본으로 자동 폴백합니다
- PWA: [`manifest.json`](./manifest.json), [`sw.js`](./sw.js), [`icon-192.png`](./icon-192.png), [`icon-512.png`](./icon-512.png)
- 테스트(개발용, 배포 대상 아님): [`test_app.py`](./test_app.py) (문법·로직), [`test_structure.py`](./test_structure.py) (DOM·문구 가드레일), [`test_smoke.py`](./test_smoke.py) (초기화·탭·필터·계산 경로 실행)

> **이 앱이 하지 않는 일**: 의료기관 알선, 예약 대행, 의약품 광고·판매, 가격 순위 매기기, 수수료 수취.
> 예약·결제·진료는 전부 해당 기관과 이용자 사이에서 이루어집니다.

### 안전장치

- 상단 고정 배너 + 모달 + 푸터에 “알선·예약 대행·의약품 광고 아님, 처방·용량은 현지 의사 판단” 명시.
- `최저가`, `1위`, `강력 추천`, `보장` 같은 유인·과장 표현 미사용(테스트로 검사).
- 가격은 전부 **각 기관 공식 페이지 공개가**이며 `2026-11 확인`으로 표기. 공개되지 않은 항목은 “공식 페이지 확인 안 됨”/“공식 확인”으로 표기.
- **가격 정렬·비교표는 단순 가격순**입니다. “공개된 1개월(4펜) 금액 기준 단순 정렬이며, 의료기관 추천·품질 우열 순위가 아닙니다.”라는 문구를 KO·EN 양쪽에 고정 표기하고, 우열·최저가 표현은 쓰지 않습니다.
- 이름·금액 등 입력값은 서버로 전송되지 않음. **체크리스트 상태와 계산기 설정(환율·금액)** 만 브라우저 localStorage에 저장되며, 이름은 저장하지 않음.
- 특정 개인의 이름·연락처·여권 표기·여행 일정 등 개인정보 미포함(테스트로 검사).

## 2. 바로 실행

```bash
# 1) 그냥 열기 — 외부 의존성 없음
open index.html            # macOS  (Windows: start index.html)

# 2) 로컬 서버로 열기(localStorage 동작이 가장 안정적)
python3 -m http.server 8000
# → http://localhost:8000
```

### 휴대폰 앱으로 설치 (PWA)

HTTPS 주소(또는 `localhost`)에서 열면 브라우저가 앱처럼 설치할 수 있게 해 줍니다.

- **Android Chrome**: 주소창 오른쪽 `⋮` → **앱 설치** / **홈 화면에 추가**
- **iPhone Safari**: 공유 버튼 → **홈 화면에 추가**

설치하면 브라우저 주소창 없이 전체 화면으로 열리고, 한 번 열어 둔 화면은 비행기 모드·지하에서도 뜹니다(서비스 워커 캐시). 파일을 `file://`로 직접 열었을 때는 서비스 워커가 등록되지 않지만 앱은 그대로 동작합니다.

## 6. 무료 배포 (5분)

정적 파일 1개라 어디든 올라갑니다. **인덱스 파일명은 `index.html`** 이어야 루트 접속 시 바로 열립니다.

### A. Vercel

```bash
cd projects/japan-mounjaro-helper
npx vercel            # 로그인 후 안내에 따라 진행 (프레임워크: Other, 빌드 없음)
npx vercel --prod     # 프로덕션 배포
```
또는 [vercel.com/new](https://vercel.com/new)에서 폴더를 드래그&드롭.

### B. Cloudflare Pages (무료, 대역폭 무제한)

```bash
cd projects/japan-mounjaro-helper
npx wrangler pages deploy . --project-name japan-mounjaro-helper
```
또는 대시보드 → **Workers & Pages → Create → Pages → Upload assets** → 폴더 업로드.

### C. GitHub Pages

```bash
cd projects/japan-mounjaro-helper
git init -b main && git add -A && git commit -m "PWA"
git remote add origin https://github.com/<계정>/japan-mounjaro-helper.git
git push -u origin main
```
저장소 → **Settings → Pages → Source: Deploy from a branch → main / (root)** → `https://<계정>.github.io/japan-mounjaro-helper/`

> 배포 대상은 `index.html`·`manifest.json`·`sw.js`·`icon-192.png`·`icon-512.png`·`README.md`(+`.nojekyll`)입니다. 테스트 스크립트와 `tools/`는 `.gitignore`로 제외되어 있습니다.

### 배포 후 체크

- 모바일에서 실제 기기로 열어 폰트·줄바꿈·하단 탭 가림 확인
- Chrome DevTools → **Application** 탭에서 Manifest 오류 없음 · Service Worker `activated` · 캐시 `jmh-v3` 생성 확인
- 홈 화면에 추가한 뒤 비행기 모드에서 재실행 → 화면이 뜨는지 확인(오프라인 캐시)
- `index.html`을 수정해 다시 배포하면, 서비스 워커 캐시는 버전(`sw.js`의 `VERSION`)을 올려야 확실히 갱신됩니다
