# 일본 마운자로 방문 도우미 — 웹앱 프로토타입 (KO/EN)

일본에서 마운자로(マンジャロ)를 자가치료 목적으로 처방·수령해 자기 나라로 가져갈 때 필요한 **공개 정보 정리 + 방문 준비 도구**를 모은 모바일 우선 웹앱입니다. **한국어(KO)와 영어(EN)를 상단에서 1탭으로 전환**할 수 있고, 오른쪽 위 `한국어 | EN` 버튼으로 언제든 바꿀 수 있습니다. 빌드 도구·외부 CDN·서버가 필요 없는 정적 앱입니다.

화면은 **2026-11 리뉴얼 디자인(jmh-v17)** 기준입니다. 상단 고정 헤더(로고·제목·언어 전환·방문자 배지), **공개가 요약 히어로**(2.5mg·5mg 공개 최소가, 언어 안내 지원 기관 수를 데이터에서 실시간 계산), 클리닉 검색창 바로 아래·기관 카드 바로 위의 **반입 준비물·체크리스트 배너(KO 전용)**, 카드마다 **3칸 가격 타일 + 펼치기식 전체 가격표·주소·비용 규칙**, 화면 아래 **5탭 고정 내비게이션(클리닉·예약·계산기·반입·실전팁)** 으로 구성됩니다. 팔레트는 오프화이트(`#f4f7f6`)·흰 카드·테일(`#0f766e`), 글꼴은 설치된 경우 Pretendard를 먼저 쓰는 시스템 글꼴 스택입니다(외부 CDN 미사용·오프라인 유지).

### 안전장치

- 상단 고정 배너 + 모달 + 푸터에 “알선·예약 대행·의약품 광고 아님, 처방·용량은 현지 의사 판단” 명시.
- **제휴 링크 표시**: 클리닉 정보·예약 링크는 수수료 없이 제공합니다. 한국어 화면의 반입 준비물 카드에만 쿠팡 파트너스 제휴 링크 3개(보냉팩·아이스팩·보냉파우치)를 두고, 카드 최상단에 쿠팡 파트너스 수수료 고지를 고대비 박스로 항상 노출합니다(접기·각주 뒤에 숨기지 않음). 영어 화면에서는 카드와 CTA가 모두 숨겨집니다. 링크의 상품 브랜드·용량·구성은 임의로 쓰지 않고 “판매 페이지에서 확인”으로 안내합니다.
- 클리닉 첫 화면 **맨 위(요약 히어로 위)** 에 “출국 전 기내 반입 체크리스트 · 준비물 확인하기 / (보냉팩·아이스팩·보냉파우치) →” 두 줄 배너를 두어, 누르면 반입 탭으로 전환하고 준비물 카드로 부드럽게 이동합니다(한국어 화면 전용, 영어 화면에서는 숨김).
- `최저가`, `1위`, `강력 추천`, `보장` 같은 유인·과장 표현 미사용(테스트로 검사).
- 가격은 전부 **각 기관 공식 페이지 공개가**이며 `2026-11 확인`으로 표기. 공개되지 않은 항목은 “공식 페이지 확인 안 됨”/“공식 확인”으로 표기.
- **가격 정렬·비교표는 단순 가격순**입니다. “공개된 1개월(4펜) 금액 기준 단순 정렬이며, 의료기관 추천·품질 우열 순위가 아닙니다.”라는 문구를 KO·EN 양쪽에 고정 표기하고, 우열·최저가 표현은 쓰지 않습니다.
- 이름·금액 등 입력값은 서버로 전송되지 않음. **체크리스트 상태와 계산기 설정(환율·금액)** 만 브라우저 localStorage에 저장되며, 이름은 저장하지 않음.
- 특정 개인의 이름·연락처·여권 표기·여행 일정 등 개인정보 미포함(테스트로 검사).

## 2. 바로 실행

```bash
# 1) 그냥 열기 — 외부 의존성 없음
open index.html            # macOS  (Windows: start index.html)

# 2) 로컬 서버로 열기(localStorage 동작이 가장 안정적)
python3 -m http.server 8000
# → http://localhost:8000
```

### 휴대폰 앱으로 설치 (PWA)

HTTPS 주소(또는 `localhost`)에서 열면 브라우저가 앱처럼 설치할 수 있게 해 줍니다.

- **Android Chrome**: 주소창 오른쪽 `⋮` → **앱 설치** / **홈 화면에 추가**
- **iPhone Safari**: 공유 버튼 → **홈 화면에 추가**

설치하면 브라우저 주소창 없이 전체 화면으로 열리고, 한 번 열어 둔 화면은 비행기 모드·지하에서도 뜹니다(서비스 워커 캐시). 파일을 `file://`로 직접 열었을 때는 서비스 워커가 등록되지 않지만 앱은 그대로 동작합니다.

## 8. 검색 노출(기술 SEO)

구글 서치콘솔·네이버 서치어드바이저에 그대로 제출할 수 있게 기술 SEO를 넣었습니다(jmh-v16). 네이버 서치어드바이저 소유확인용 `naver-site-verification` 메타태그도 head에 들어 있습니다(jmh-v17).

| 항목 | 내용 |
|---|---|
| `<title>` | `일본 마운자로 클리닉 11곳 공개가 비교 · 반입·대마도 수령 가이드` |

| canonical | `https://swbae123456.github.io/Japan-mounjaro-helper/` |
| hreflang | `ko` = 루트, `en` = `?lang=en`, `x-default` = 루트 |
| Open Graph | `og:type/site_name/title/description/url/locale(ko_KR)/locale:alternate(en_US)/image` — `og:image`는 실제 파일인 `icon-512.png`(512×512) |
